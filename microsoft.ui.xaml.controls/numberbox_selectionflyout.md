# Microsoft.UI.Xaml.Controls.NumberBox.SelectionFlyout

<!--

## -description

Gets or sets the flyout that is shown when text is selected, or `null` if no flyout is shown.

**This documentation applies to WinUI 2 for UWP** (for [WinUI](/windows/apps/winui/winui3/) in the [Windows App SDK](/windows/apps/windows-app-sdk/), see the **[Windows App SDK namespaces](/windows/windows-app-sdk/api/winrt/)**).

## -property-value

The flyout that is shown when text is selected, or `null` if no flyout is shown. The default is a [TextCommandBarFlyout](textcommandbarflyout.md)
