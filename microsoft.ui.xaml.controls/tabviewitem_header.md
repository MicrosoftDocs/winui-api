# Microsoft.UI.Xaml.Controls.TabViewItem.Header

<!--
public object Header { get; set; }
-->

## -description

Gets or sets the content that appears inside the tab strip to represent the tab.

**This documentation applies to WinUI 2 for UWP** (for [WinUI](/windows/apps/winui/winui3/) in the [Windows App SDK](/windows/apps/windows-app-sdk/), see the **[Windows App SDK namespaces](/windows/windows-app-sdk/api/winrt/)**).

## -property-value

The content that appears inside the tab strip to represent the tab.

## -remarks

The Header of the TabViewItem is typically just a text label corresponding to the title of the tab, but can be any object.

If [IconSource](tabviewitem_iconsource.md) is set, the Header content appears inside the tab UI to the right of the icon.
