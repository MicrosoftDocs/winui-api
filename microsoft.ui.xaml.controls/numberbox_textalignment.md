# Microsoft.UI.Xaml.Controls.NumberBox.TextAlignment

<!--
public Windows.UI.Xaml.TextAlignment TextAlignment { get; set; }
-->

## -description

Gets or sets a value that specifies how the text should be horizontally aligned in the text box.

## -property-value

One of the `TextAlignment` enumeration values. The default is `Left`.
